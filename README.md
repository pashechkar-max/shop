# ServiceHub

Учебный проект на Django — мини-сайт каталога услуг с базовой регистрацией, авторизацией и управлением записями услуг.

## О проекте

Это учебный пет-проект, созданный для изучения Django, маршрутизации, моделей, форм, шаблонов и аутентификации пользователей. Проект представляет собой простой сервисный сайт, где можно просматривать список услуг, открывать карточку каждой услуги и добавлять новые записи для пользователей с ролью staff.

## Основные возможности

- просмотр главной страницы;
- регистрация и вход пользователей;
- список услуг;
- карточка отдельной услуги;
- добавление новых услуг только для staff-пользователей;
- профиль пользователя;
- административная панель Django.

## Технологии

- Python
- Django
- SQLite
- HTML / Django templates

## Цель проекта

Изучение основ веб-разработки на Django и закрепление практики работы с:

- моделями и базой данных;
- формами;
- представлениями;
- URL-маршрутами;
- шаблонами;
- авторизацией пользователей.

## Статус

Учебный проект / demo.

## Запуск проекта

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```
