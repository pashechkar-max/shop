# Shop

Минималистичный веб-сервис на Django для каталога услуг/товаров с возможностью регистрации пользователей, просмотра карточек услуг и добавления новых записей администраторами.

## Что это за проект

Это не полноценный интернет-магазин с корзиной, оплатой и каталогом товаров в классическом смысле. Скорее всего это учебный / демонстрационный проект сайта-сервиса, который позволяет:

- просматривать главную страницу;
- регистрироваться и входить в систему;
- просматривать список услуг;
- открывать отдельную страницу конкретной услуги;
- добавлять новые услуги только для сотрудников/администратора;
- просматривать профиль пользователя.

Проект построен на Django и использует SQLite в качестве локальной базы данных.

## Основные функции

- Главная страница (`/`)
- Регистрация (`/register/`)
- Вход (`/login/`)
- Выход (`/logout/`)
- Список услуг (`/service/`)
- Карточка услуги (`/service/<int:service_id>/`)
- Добавление услуги (`/service/add/`) — доступно только staff-пользователям
- Профиль (`/profile/`)

## Модель данных

В проекте есть модель `Service`:

```python
class Service(models.Model):
    name = models.CharField(max_length=100)
    description = models.TextField()
```

То есть каждая услуга представлена названием и описанием.

## Форма регистрации

Подключена стандартная форма Django `UserCreationForm` с полем email:

```python
class RegisterForm(UserCreationForm):
    email = forms.EmailField()
```

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/pashechkar-max/shop.git
cd shop
```

2. Создайте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate   # Linux/macOS
# или
venv\Scripts\activate      # Windows
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Выполните миграции:

```bash
python manage.py migrate
```

5. Запустите сервер:

```bash
python manage.py runserver
```

После этого проект будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Пользовательские роли

- обычный пользователь может регистрироваться и просматривать услуги;
- `staff`-пользователь может добавлять новые услуги через страницу `/service/add/`;
- обычные пользователи не могут получить доступ к этой странице.

## Примечание

Это учебный/демо проект, поэтому в нём нет сложной логики интернет-магазина: без корзины, без оплаты, без фильтрации, без REST API и без полноценной системы заказов. Основная идея — демонстрация работы Django-сайта с каталогом услуг и базовой авторизацией.
